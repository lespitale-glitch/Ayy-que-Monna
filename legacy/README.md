# legacy/ — respaldo de la web original

Esta carpeta guarda la web HTML/CSS original de Ayy Que Monna **solo como referencia**.
No se modifica ni se importa desde la app nueva.

## Cómo completar el respaldo
1. Copiar aquí los archivos `.html`, `.css` y `.js` de la web original, manteniendo sus carpetas.
2. Las imágenes pesadas (jpg, png, tif, heic, psd…) quedan ignoradas por Git automáticamente
   (ver `.gitignore`); las fotos originales completas van en `fotos-originales/`, fuera de Git.
3. Commit: `git add legacy && git commit -m "chore: respaldo de la web original"`.

Estado: **pendiente** — los archivos originales todavía no se subieron al repositorio.
